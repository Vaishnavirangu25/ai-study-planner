# AI-Based Smart Study Planner

An AI-powered study planner designed to help students organize their studies, manage subjects, and plan their learning effectively.

## Features

- Student information management
- Subject-wise study planning
- Study schedule organization
- AI-assisted study planning
- Simple and user-friendly Streamlit interface
- Data storage using SQLite

## Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- NumPy
- Scikit-learn
- Generative AI

## How to Run

```bash
py -m streamlit run app.py
